## ✨ 核心特色與功能架構

### 1. 📊 26 頁高畫質白底大字教學簡報
* **白底高對比投影設計**：主色調為森林翠綠與天藍，文字加粗放大，投影不吃光、教室後排清晰可見。
* **生動易懂的實務範例**：將 ISO 14067、截斷原則（1%/5%）、隨團人員分子分母規定、一級數據門檻（≥10%）、嚴禁碳抵換等複雜規範，轉化為生活情境解說。
* **動態情境模擬試算器（第 20 頁）**：課堂上可即時拉動食材、柴油里程、用電度數，現場試算人均碳足跡。
* **鍵盤導航支援**：`←` / `→` 切換、`Space` 下一頁、`O` 投影片總覽跳頁、`F` 全螢幕、`Ctrl+P` 講義列印。

### 2. 📝 115年遊程碳足跡實作學習單系統 (單元 1-1 & 1-2)
* **1-1 低碳遊程盤點與碳排計算**：交通、住宿、餐飲、活動、廢棄物、行政門市六大構面，內建官方排放係數自動加總。
* **1-2 減碳方案研擬與遊程優化**：熱點診斷排序、優化前後雙軌比對、即時計算減碳量與減碳率（%）、落地行動方案時程表。
* **宜蘭冬山茶韻米香典範案例**：內建一鍵載入高雄 147 號有機米、在地放山土雞、台鐵+電輔車之完整數據（人均碳排 26.0 kg ➔ 6.7 kg，減碳 74.2%）。
* **對外溝通「遊客低碳資訊小卡」**：一鍵彈出視覺化社群推廣圖卡。
* **無紙化與備份**：支援本機 JSON 匯出/匯入與 A4 完美格式列印。

### 3. ⚡ 鍵盤一秒切換：按字母鍵 `W`
在簡報模式下按 <kbd>W</kbd> 即可無縫切換至學習單；在學習單中按 <kbd>W</kbd> 或點擊 `⬅️ 返回簡報` 即刻返回原投影片頁面。
